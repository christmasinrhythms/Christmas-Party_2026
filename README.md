# Christmas in Rhythms · Christmas Party 2026

The event site is published at [Christmas in Rhythms](https://christmasinrhythms.github.io/Christmas-Party_2026/).

- `room.html#dress` opens the Grand Hall, where guests can pick a dress-code room.
- `room.html#reels` opens the Xmas Video Challenge. Add `?lang=zh` before the hash for Traditional Chinese.
- `assets/interior/room-photos.json` lists the pictures and display order for the four galleries.
- `assets/interior/reels/` contains the three MP4s played by each room’s TV.
- `Archive/2026-11-25-e3fdf56/` contains the previous site.
